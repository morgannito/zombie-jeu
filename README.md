# Jeu de Zombie Multijoueur

Un jeu de survie zombie en temps réel sur navigateur avec support multijoueur.

## Fonctionnalités

- Multijoueur en temps réel avec Socket.IO
- Mouvement fluide des joueurs (WASD ou flèches)
- Vagues de zombies avec IA
- Système de combat (tir à la souris)
- Score et système de survie
- Interface HTML5 Canvas

## Installation

```bash
npm install
```

## Démarrage

```bash
npm start
```

Ouvrez plusieurs onglets sur `http://localhost:3000` pour tester le multijoueur !

## Contrôles

- **WASD** ou **Flèches** : Déplacement
- **Clic gauche** : Tirer
- **Souris** : Viser

## Technologies

- Node.js + Express
- Socket.IO (WebSockets)
- HTML5 Canvas
- JavaScript ES6+
